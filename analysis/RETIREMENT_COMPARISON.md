# 退休1 vs 退休5：固定生活費＋不足質押的長期量化比較

研究日期：2026-09-14。session: 01a09d9b-8e2f-7fc2-972a-f773acf622df。

## 結論

沒有不依賴報酬假設的絕對贏家。原始歷史重抽偏向退休1；消除台股與那斯達克的歷史超額報酬後，退休5的高負債比路徑較少。如果不願把退休計畫建立在台股／科技股持續領先全球股票的假設上，偏向退休5；但其基準提領不足150萬元，加入質押後依然有顯著尾部風險，不能宣稱免質押或零破產。

## 完全共用的條件

- 本金3,000萬元、初始無債務、40年、固定名目生活費150萬元／年。主情境不加通膨。
- 借款年有效利率3%，按月複利資本化；5%另測。利息在150万元生活費之外。
- 每年初按當時資產執行提領與借款，接著逐月報酬及計息；這是年度現金流近似，不是逐月領息、逐月花費的完整實務模型。
- 現金超過支出先還債，多餘現金放回債券／緩衝池。無外部年金或收入。
- 退休1初始009816 20%、00662 20%、00984B 50%、00685L 10%，不再平衡。債券配息首年94.05萬元，基準固定每年此金額，但不能超過剩餘債券價值；另測每年依當時債券市值6.27%給付、固定67.5萬元給付。固定配息是假設，不是基金承諾；直接套用舊紀錄6.27%會有不確定性。
- 退休5初始股票2,700萬元、短債300萬元；每年先從成長池移4%進短債，再從合計短債領25%；生活費不足借款。借款不投入股票。股票股利包含於總報酬，沒有再算一次現金收入。
- 所有資產報酬為含息總報酬代理，現金配息／提領均從資產扣掉，內部轉移只移一次，避免配息和含息報酬雙重計算。
- 主指標：40年內任一次「借款／總投資資產 ≥ 50%」的路徑占比。50%是研究警戒線，不是實際券商斷頭規定。另存60%、70%結果。
- 主情境假設全部投資資產均可作擔保；另測排除正二部位。實際質押資格、折算率、集中度限制、續借及利率會依機構／契約不同。
- 跨線後腳本仍續算診斷用假想路徑，並不代表銀行願意繼續借款。主要結論只採第一次跨線的路徑占比；未受限期末資產不可當成可實現退休財富。

2026-09-14從Yahoo Finance以yfinance下載日資料，截止2026-08-31，排除未完成的9月。保留原始資料於data/及月報酬於monthly_returns.csv。

本次實際下載的TWD=X在2004-11至2006-04缺整段資料，與舊WORKLOG聲稱可連續使用2004年起資料不一致。未填補或串接缺失月份，改用最長完整連續段：2006-06至2026-08，共243個月（20.25年）。包含完整2008金融海嘯、2020與2022；不包含2000科技泡沫破裂。歷史起始資產估值是2006年5月底，首個報酬月是6月。

原始樣本年複合報酬：台股代理13.68%、QQQ台幣16.31%、正二代理22.81%、全球股票8.48%、LQD4.11%、短債1.48%。這些是本樣本結果，不能視為未來報酬預測。

## 方法

4,000條40年路徑，以12個連續月份為區塊、隨機抽有放回，共同抽取所有資產，保留同月跨資產相關；固定亂數種子9142026。另測24個月區塊、30年期限及2010年後真實VT／長公司債時期。

「股票同為8%」：把原始月對數報酬的平均移到年複合8%，台股、QQQ、全球股票分別調整，保留其波動與相關。正二以台股調整量兩倍調整；不是將正二固定為16%。重抽後每條路徑報酬仍不同。8%是透明的敏感度假設，不是合理報酬的認證或預測。

## 核心結果

下表為40年內曾超過50%負債比的模擬路徑占比，越低越好；不是實際破產機率，也不是基金真實40年回測。

| 情境 | 退休1 | 退休5 |
|---|---:|---:|
| 原始歷史報酬、利息3%、固定支出 | 4.9% | 21.4% |
| 股票同為8%、利息3%、固定支出 | 49.5% | 25.1% |
| 股票同為8%、利息5% | 59.8% | 29.9% |
| 股票同為8%、支出每年加2% | 66.4% | 44.2% |
| 股票同為8%、改用長天期公司債代理 | 46.7% | 25.1% |
| 股票同為8%、退休1改按市值6.27%配息 | 52.5% | 25.1% |
| 股票同為8%、退休1固定配息降至67.5萬 | 54.7% | 25.1% |

原始歷史基準改24月區塊：退休1 4.4%、退休5 22.7%；基準利率5%：7.9%／25.9%；基準加入2%支出成長：11.1%／38.8%。4,000條路徑的抽樣誤差大致是百分點量級；代理、制度與報酬假設的不確定性更大，不宜解讀小數點差距。

## 勝負分界

全球股票固定年複合8%假設，只提高退休1的台股、QQQ平均報酬（保留歷史波動與相關、正二同步調整）：

| 台股與QQQ目標報酬 | 退休1跨50%占比 | 退休5跨50%占比 |
|---|---:|---:|
| 8% | 49.5% | 25.1% |
| 9% | 39.3% | 25.1% |
| 10% | 30.5% | 25.1% |
| 11% | 21.7% | 25.1% |
| 12% | 16.4% | 25.1% |

在這組特定假設下，兩個股票腿需要約比全球股票多2–3個百分點的年複合報酬，退休1才翻成較少觸線。這不是可移植的普遍門檻，更不是未來報酬保證。

## 真實順序的代理回放

2006年5月底投入、2006年6月起花費，至2026年8月底：退休1期末扣債淨資產38,959萬元、退休5 5,581萬元；期間最高負債比15.7%／26.6%，均未觸50%。這是約20年，不是40年。末段只走3個月但在年初已領全年費用，屬偏保守的年度近似。

退休1的高期末值受台股／科技股與正二過去強勁報酬、不再平衡造成權重漂移支配。不能把此數字或40年未受限外推的巨大期末值當退休預期。

## 該如何使用結論

- 如果判斷台股與Nasdaq可持續超額報酬，且接受正二持倉漂移，這份歷史資料支持退休1。
- 若不依賴上述超額報酬，退休5在一致報酬假設及本次借款規則下較有利。
- 加入借款後，退休5的收入平滑不等於擔保品穩定；股票低迷時收入下降、負債攀升，必須看最高負債比。
- 兩者都沒有被證明能安全保證每年150萬元。月末而非逐日的追繳檢查、固定利率、忽略稅／交易成本／展期限制、ETF代理與只有一次完整大型金融危機等限制都會影響結果。
- 下一步若要決定實際配置，應用真實質押契約補上認列擔保品、維持率、利息現付或資本化、最高借款限制，再評估支出底線與其他收入。
