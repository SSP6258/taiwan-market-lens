## 為什麼製作台股比較室？

股票與 ETF 的單位價格不同，直接把價格放在同一張圖上，不容易看出誰漲得多、誰波動大。台股比較室把每檔標的的共同起始日設為 **0.0%**，讓你從相同時間起點比較走勢，再搭配回撤與風險指標，觀察不同資產的特性。

設計目標是「快速選股、清楚比較、容易操作」：最多比較 12 檔，所有曲線使用實線與不同配色，畫面數值統一保留小數 1 位。這是一個歷史資料研究工具，沒有下單功能，也不提供未來報酬預測。

## 如何使用

1. **選擇標的**：展開左側「比較設定」，在「股票與 ETF」搜尋代碼或中文名稱。點標籤的 × 可移除；「查看完整已選清單」可檢查所有選項。
2. **新增股票**：在「其他股票代碼」輸入，例如 `00908, 00998A`，點「加入上方清單」（手機不需 Enter，電腦亦可按 Enter）。成功後會置頂，並顯示結果訊息。可用 `.TW` 指定上市、`.TWO` 指定上櫃。
3. **設定區間**：選擇 3 月至 5 年，或自訂起訖日期。系統只比較各檔都有有效行情的共同交易日。
4. **選擇價格基準**：「還原價格」採來源提供的股利與分割調整價格；「收盤價」呈現未還原價格，除息或分割可能造成跳動。
5. **閱讀圖表**：切換「累積漲跌幅」或「歷史回撤」。移動游標查看同一天的數值；拖曳平移、滾輪縮放，點圖例可隱藏曲線。「重設縮放」與「顯示全部」可恢復視圖。
6. **查看完整結果**：上方指標卡依區間報酬由高至低顯示前 4 檔（由左至右，換行後接續）；下方圖表與報酬風險表涵蓋所有成功載入的標的。「下載比較資料 CSV」匯出共同日期的累積漲跌幅。

## 數字是如何算出來的？

| 指標 | 計算方式 | 如何解讀 |
| --- | --- | --- |
| 累積漲跌幅 |（當日價格 ÷ 共同起始日價格 − 1）× 100% | 100 元變成 110 元，為 +10.0%。 |
| 歷史回撤 |（當日價格 ÷ 截至當日的區間最高價 − 1）× 100% | 從 100 元高點跌至 90 元，為 −10.0%；創高時為 0.0%。 |
| 最大回撤 | 共同交易日取樣中最深的回撤 | 觀察這段比較期間從高點跌得多深。 |
| 年化報酬 |〔（期末價格 ÷ 期初價格）的（365.25 ÷ 實際天數）次方 − 1〕× 100% | 換算成年複合成長率；不足 365 天不顯示。 |
| 年化波動 | 每日報酬的樣本標準差 × √252 × 100% | 使用各檔原始日報酬、限定在共同起訖期間；衡量波動大小，不代表獲利機率。 |

**為什麼期間會變短？** 新掛牌標的或來源資料缺漏，可能沒有完整的指定區間。程式保留每檔都有有效正價格的日期交集，不補空值，也不製造行情；提示會列出限制共同起日或迄日的標的及日期。區間內缺漏的交易日也不會納入共同圖表。

有效資料起日不一定等於掛牌日。回撤的高點是「本次比較區間、共同交易日」中的高點，並非上市以來最高價。畫面與匯出四捨五入至小數 1 位，內部計算保留原始精度。

## 資料從哪裡來？

**歷史價格**由執行 App 的主機透過 yfinance 向 Yahoo Finance 取得日線資料，包含 Close 與 Adj Close。每檔、每組日期區間快取 1 小時，最多保留 256 組快取；同時最多使用 4 個請求取得行情。按「重新取得資料」會清除目前所選標的與區間的行情快取並重取。

**中文名稱與市場別**來自證交所 ISIN 上市／上櫃名錄，快取期限為 6 小時，期限過後在下次執行時重新嘗試更新，並非背景排程。連線失敗時使用隨專案提供的名錄備援，畫面會提醒；未收錄的名稱會標示「名稱暫未取得」。名稱名錄與行情是不同資料來源，查得到名稱不代表一定能取得行情。

若單一標的行情失敗，App 會明確列出並排除該檔；全部失敗時顯示錯誤，不使用模擬資料。Yahoo 資料可能延遲、修訂或暫時無法取得，當日資料也可能尚未收盤。

## Beta 分析：對市場漲跌有多敏感？

此分頁衡量標的日報酬對基準的敏感程度，與自身波動大小不同；低 Beta 不一定代表低風險。

### 操作步驟

1. 在左側選好股票與日期，開啟「Beta 分析」。
2. 選擇比較基準：預設 **0050 元大台灣50**，亦可選 **台灣加權指數（大盤）· ^TWII** 或其他股票／ETF。基準不占 12 檔名額。
3. 查看敏感度排序圖：金色虛線為 Beta 1.0。表格提供 Beta、R²、樣本數與實際期間。
4. 選擇要查看的標的，閱讀散點圖；X 軸顯示所選基準每日報酬，Y 軸顯示所選標的每日報酬，兩軸皆標示名稱。

### 數值如何解讀

| 指標 | 意義 |
| --- | --- |
| Beta 1.00 | 對基準的敏感程度相近，不代表每天漲跌相同。 |
| Beta 1.50 | 歷史回歸中，基準日報酬每增加 1 個百分點，標的擬合日報酬增加約 1.5 個百分點。 |
| Beta 0.50 | 對基準的敏感程度較低，但仍可能有其他風險。 |
| Beta 小於 0 | 本次樣本中呈反向線性關係。 |
| R² 0.43 | 線性模型可解釋約 43.0% 的標的日報酬變異；不是預測正確率或獲利機率。 |

**散點圖**：每點代表一天，金線為含截距的最小平方法回歸。斜率為 Beta；向上為正相關，向下為負相關。點越貼近直線，通常 R² 越高。Beta 1.50 並不表示大盤明天漲 1.0%，標的一定漲 1.5%。

**計算**：先在日期聯集計算日報酬，再排除缺漏，不補值。Beta＝樣本共變異數 ÷ 基準樣本變異數；R² 為相關係數平方。至少需 20 筆有效日報酬，不足 60 筆會提醒樣本偏少。基準零波動時無法估計 Beta；標的零波動時 R² 不定義。係數顯示兩位小數。

**限制**：0050 是 ETF 代理基準，不是完整大盤。^TWII 採加權價格指數收盤值，不含股息再投資；標的若採還原價格，兩者配息處理不同。每檔各自對齊基準，期間可能不同。海外、債券與黃金 ETF 對台股的低 Beta，不等於安全；收盤時間、匯率、交易日差異也可能影響結果。歷史關係不代表因果或未來績效。

## 分散效果的文字解讀

波動圖的金色虛線是**個別標的波動的算術平均，不含組合**，只是比較基準，不是另一個實際投資組合。青綠色長條才是起初等權重、之後持有不再平衡的組合波動。組合低於此平均，不代表比每一檔都穩定。

「數據解讀」由程式直接計算，比較波動、回撤與最高／最低相關配對。最低相關僅是清單內相對位置，仍可能高度正相關。相關性與組合試算可能採不同期間，請對照各自日期。

「AI 深入解讀」為選用功能，需設定 Hugging Face 模型與金鑰，未設定時停用。點擊才送出統計摘要；同模型與摘要在本次連線中可重用結果。AI 失敗不影響基本解讀，文字仍需對照原始數據。

## 軟體架構

資料流：**使用者設定 → Python 取得與快取資料 → pandas 對齊日期及計算 → Streamlit 呈現指標與表格 → Lightweight Charts 繪圖**。

| 層次 | 使用技術／檔案 | 負責工作 |
| --- | --- | --- |
| 操作介面 | Streamlit · `streamlit_app.py` | 選股、日期、提示、分頁、報酬表與 CSV 匯出；以 Session State 保存目前連線的選項。 |
| 行情與分析 | Python、pandas、NumPy、yfinance · `market.py` | 取得日線、驗證價格、共同日期對齊、計算報酬與風險。 |
| 證券名錄 | requests · `securities.py`、`data/securities.json` | 取得中文名稱與上市／上櫃分類，提供離線備援。 |
| 互動圖表 | Streamlit Components v2、JavaScript · `lightweight_chart.py` | 將資料傳到瀏覽器，處理游標、縮放及曲線開關。 |
| 圖表引擎 | TradingView Lightweight Charts 5.0.9 · `vendor/` | 在瀏覽器繪製曲線；程式隨專案提供，不依賴外部 CDN 載入。 |
| 啟動與樣式 | `run.bat`、`launch.py`、`.streamlit/config.toml` | 啟動本地服務、處理連接埠占用、設定主題。 |

圖表縮放與圖例開關在瀏覽器端處理，不會重新查詢行情。更改選股或區間會重新執行 Python 頁面流程，仍可使用有效快取。此版本沒有獨立資料庫，選股清單也不是帳號永久收藏；重新建立連線可能回到預設。

## 本地與雲端如何運作？

**本地端**：雙擊 `run.bat` 後，Python 服務在你的電腦運作，瀏覽器連到本機網址。保留啟動視窗，按 Ctrl+C 停止。再次執行會重用已開啟的同一 App；若預設 8501 連接埠被其他服務占用，會尋找 8502–8510 的可用位置。

**雲端部署**：相同 Python 程式改由雲端主機執行，行情及名錄也由雲端主機對外抓取，訪客透過瀏覽器操作。需要一併部署程式、套件清單、圖表資源、名稱備援及設定檔；此版本的資料取得方式不需使用者輸入 API key。雲端主機必須能連線到資料來源，主機重啟後可能需要重新取得快取資料。目前專案為本地實作，這個說明頁不代表已完成公開部署。

## 常見問題

**為什麼不能再加入？** 上限為 12 檔。超過上限、代碼格式錯誤或無法確認資料時，都會顯示訊息；新增失敗不會替換原有清單。重複標的不會重複加入。

**為什麼標籤看不完整？** 選股區可以捲動，也可展開完整已選清單。新增標的會置頂。

**為什麼與券商績效不同？** 比較區間、資料來源、還原方式及取樣日期可能不同；這裡不計算你的買入成本、稅金、交易費用或實際配息再投資。

**為什麼年化報酬空白？** 共同期間不足一年時刻意留空，避免把短期漲跌過度外推。

**換一檔股票後，其他曲線也變了？** 共同起日可能跟著改變，每條線會以新的共同起日重新設為 0.0%，因此報酬與風險指標也會重算。

### 手機與筆電操作

手機點左上角箭頭展開比較設定；輸入代碼後點「加入上方清單」。報酬卡在手機改為單欄，筆電並排。圖表可左右拖曳、雙指縮放、長按查看數值；上下滑動仍可捲動頁面。圖例按鈕可直接點選，表格可左右滑動。

## 自訂組合比重

在側邊欄展開「組合配置」，輸入每檔起始比重後點「套用配置」。合計需為 100.0%，錯誤時保留原配置；可一鍵恢復等權重。選股清單變更會恢復等權重。自訂後組合報酬、波動、回撤同步重算，金色參考線採起始比重加權的個別波動。相關性與單檔 Beta 不受影響。0.0% 的標的不投入，但仍影響共同資料期間；如不需比較可從清單移除。

### 共用配置與組合 Beta

側邊欄的配置同時供分散效果與 Beta 分析使用。Beta 排序表及散點選單包含「等權重組合」或「自訂配置組合」。程式先依起始比重建立持有、不再平衡的組合價值，再計算日報酬並對基準回歸；不是將單檔 Beta 直接加權平均。單檔 Beta 與相關性不受比重影響。組合先採最長完整行情區段，再與基準對齊，請以各自顯示的期間為準。若部分選股行情失敗，組合暫停計算，不會自動將剩餘權重放大。

## 總投入金額與配息試算

側邊欄金額以新台幣「萬元」輸入（例如 10 代表 100,000 元），結果以元顯示。金額為選填，空白或零維持原百分比分析，不查配息。填入正數後，在「投資報酬」獨立分頁呈現起始配置、期末價值、損益及價值曲線；採最長完整行情區段、小數單位、持有不再平衡，未計稅費。最大金額回撤是資產價值與先前高點的最大差額。

「現金配息與殖利率」需另外開啟才查資料，最多四個平行請求、快取一小時。使用 Close 與分割調整單位的除息事件，配息不再投入，不再加到 Adj Close。期初收盤買入，當日除息不納入。除息不代表實際付款入帳，來源缺漏時不把失敗當成零。分割調整單位不是當時實際成交股數。

期間成本配息率＝期間除息金額÷初始投入，未年化。期末近12月殖利率＝試算期末前12月每股配息÷期末價格，並非今日殖利率；來源覆蓋不足一年留空。資料服務可能修訂或漏報，本試算不是正式配息帳本。

### 每月配息來源圖

金額分頁使用各檔堆疊長條呈現每月除息金額，保留零配息月份，可展開每月明細。月份平均包含首尾不完整月份，不等於穩定月收入。此圖依除息日歸月，並非付款入帳日；評估生活費時需另確認付款日期與現金準備，未來配息不保證。

除息明細的「當次配息殖利率」＝當次每單位配息 ÷ 除息前一筆交易日收盤價 × 100%，不年化，也不是以期初成本計算。前日價格無效時留空；價格與配息皆採來源的分割調整單位。

「投資報酬」分為「總報酬」與「配息」兩個子分頁。總報酬顯示金額與區間報酬率，沿用選定價格基準；收盤價模式不含現金配息，還原模式不再加配息。配息子分頁提供獨立含息損益、月配息分布及事件明細。


### 占比追蹤
總報酬頁以每月最後有效交易日的各檔試算價值除以組合價值，呈現不再平衡後的占比變化。首尾月份標示一位小數，首月為月末而非買入日，末月可能尚未結束。沿用相同比價基準：還原價格為含配息調整的價值占比，不等於實際持股市值占比。圖表沿用現有行情，不新增網路請求。投資區塊使用局部更新，操作配息開關不重跑整個主頁。
